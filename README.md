#### 四个区域和核心命令解释：
工作区：编辑文件的区域。\
暂存区：用于暂存，准备提交的区域。\
本地仓库：提交文件形容，提供对比。\
远程仓库：同步版本至GitHub。\
git add：将工作区变更存入暂存区。\
git commit：将暂存区内容提交到本地仓库。\
git push：将本地仓库变更到远程仓库。
